# Fieldnotes

[English](README.md) | **简体中文**

为 [TREK](https://github.com/mauriceboe/TREK) 打造的私人 Markdown 旅行知识库。一条经验只写一次，按文件夹整理好，再带入任何一次旅行：可以是跟随原文更新的实时引用，也可以是由旅行永久保留的独立快照。

Fieldnotes 会在 TREK 的导航栏中添加 **Fieldnotes** 页面。配套插件 [Trip Fieldnotes](https://github.com/Tangerineeew/fieldnotes-trip) 则在每次旅行内添加一个标签页，旅行成员都能在那里阅读分享给这次旅行的笔记。

## 功能介绍

- **只属于你的图书馆。** 笔记默认私有。可以用带 emoji 图标的多级文件夹整理，按名称或日期排序，并搜索标题、正文和属性值。
- **所见即所得的 Markdown 编辑器。** 标题、列表、表格、引用和链接在输入时即时渲染，语法符号只在光标附近出现。输入 `/` 插入块，直接粘贴或拖入图片，用 `[[笔记标题]]` 或 `[[文件夹/笔记标题]]` 链接其他笔记。
- **类型化属性。** 可以为笔记添加文本、数字、日期、单选、多选、复选框、链接、清单和最后编辑时间等字段。选项会显示为彩色标签，清单会显示完成进度。
- **有分寸的分享。** 可以邀请同行的旅伴成为单篇笔记或整个文件夹的编辑者或查看者。谁能看到笔记、是否对所有已登录用户公开、放在哪个文件夹，都只由所有者决定。
- **实时协同编辑。** 编辑者同时打开同一篇笔记时，会编辑同一份共享文档，能看到彼此的光标，也不会互相覆盖修改。
- **把笔记带入旅行。** 实时引用会向旅行全体成员展示最新版本；快照会把笔记连同图片副本一起冻结，即使删除原文也会留在旅行中。还可以把任意 500 字以内的摘录复制到行程中的某一天。
- **跟着笔记走的图片。** 粘贴的图片会在浏览器中压缩后存入插件自己的数据库，不依赖任何外部图床。也支持管理员已允许的网站上的图片链接。
- **十四种语言。** 界面和错误提示都跟随 TREK 的语言设置：英语、简体中文、繁体中文、德语、西班牙语、法语、匈牙利语、荷兰语、巴西葡萄牙语、捷克语、波兰语、俄语、意大利语和阿拉伯语，并支持从右到左排版。

## 权限说明

Fieldnotes 把笔记、文件夹、分享设置和图片保存在插件自己的数据库中，只向 TREK 申请上述功能真正需要的权限。每个请求都以当前登录用户的身份执行，因此 TREK 本身的旅行角色权限依然有效。

| 权限 | 用途 |
|---|---|
| `db:own` | 在插件自己的数据库中保存笔记、文件夹、协作者、旅行关联、快照和上传的图片。 |
| `db:read:trips` | 为「带入旅行」列出你的旅行及其日程，并在展示共享笔记前核对旅行成员身份。可邀请的成员就是与你同在某次旅行中的人。 |
| `db:read:files` | 解析引用行程附件的图片，地址格式为 `fieldnotes://trip-file/<旅行>/<文件>`。 |
| `db:read:files:content` | 读取这些行程附件图片的内容，用于显示以及复制到快照中。 |
| `db:meta` | 在关联、移除或整理旅行笔记之前，确认你有权编辑这次旅行。Fieldnotes 会请求 TREK 删除一个临时元数据键，只有旅行编辑者才能执行这一操作；插件从不保存旅行元数据。 |
| `db:write:daynotes` | 把你选择的摘录复制到行程中的某一天，TREK 仍会检查日程编辑权限。 |
| `db:read:users` | 显示正在与你一起编辑笔记的成员名字。 |
| `hook:user-data` | 在 TREK 导出或删除账户时，一并导出或清除该用户的笔记、文件夹、图片和旅行关联。 |
| `http:outbound` | 在服务器端加载笔记中以 `https://` 链接嵌入的图片，读者的浏览器不会直接访问对方网站。 |

插件声明了 `operatorEgress`，在管理员允许某个域名之前，无法访问任何网站。私有网络和本地地址始终会被拒绝，重定向在跟随之前也会重新检查。

## 安装与设置

1. 在 TREK 中打开 **管理后台 → 插件**，先安装 **Fieldnotes**，再安装 [Trip Fieldnotes](https://github.com/Tangerineeew/fieldnotes-trip)。
2. 先启用 **Fieldnotes**，再启用 **Trip Fieldnotes**，因为旅行标签页依赖图书馆。上传后的插件默认处于停用状态。
3. 可选：如果需要显示笔记中引用自其他网站的图片，在 Fieldnotes 的 **管理后台 → 插件 → ⋯ → 允许的主机** 中添加这些域名，例如 `*.example.com`。直接复制图片本身再粘贴进笔记，则不需要任何配置。
4. 从导航栏打开 **Fieldnotes**，写下第一篇笔记。

卸载 Fieldnotes 会删除它保存的所有笔记、文件夹、图片和分享设置。如果日后可能还需要这些数据，请先备份 TREK。升级到新版本会保留全部数据。

## 开发

仓库根目录就是构建好的插件，也就是 TREK 实际安装的内容。源码位于 [`source/`](./source)：`client/` 是 React 前端，`server/` 是服务端，`shared/` 存放前后端共用的限制参数，`tests/` 是测试。

```bash
cd source
npm ci
npm run check   # TypeScript 类型检查
npm test        # 服务端、前端和翻译测试
npm run pack    # 生成 dist/fieldnotes.zip 和 dist/fieldnotes-trip.zip
```

所有界面文案都通过 `client/i18n.ts` 翻译；任何一种语言缺少译文时，翻译测试都会失败。
