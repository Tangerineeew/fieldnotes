# Fieldnotes

[English](README.md) | **简体中文**

**记录下旅途中积累的经验，下次出发随时用得上。**

Fieldnotes 是自托管旅行规划工具 [TREK](https://github.com/mauriceboe/TREK) 里的一座私人 Markdown 图书馆。怎样在一座城市里出行、寺院里有哪些礼仪、哪些 App 值得装，都先收进自己的图书馆，需要时再以实时引用或快照的方式带进每一次旅行。

适用于 TREK 4.1 及以上版本，搭配 [Trip Fieldnotes](https://github.com/Tangerineeew/fieldnotes-trip) 可在旅行中阅读笔记 · 持续维护中，见 [Releases](https://github.com/Tangerineeew/fieldnotes/releases) · [MIT 许可证](./LICENSE)

## 功能

TREK 自带的笔记只属于某一次旅行。Fieldnotes 把笔记放在一座属于你自己的图书馆里，可以在多次旅行中反复使用：云南交通速查写一次，就能放进每一次云南之行，之后的修改也会跟着同步。和放在 Notion 或 Obsidian 里的笔记不同，它们留在你自己的 TREK 服务器上，同行的人在正在规划的那次旅行里就能读到。

单独安装时，Fieldnotes 就是你的图书馆。想在旅行里阅读笔记，再加上配套插件 [Trip Fieldnotes](https://github.com/Tangerineeew/fieldnotes-trip)，它会在每次旅行中添加一个笔记标签页：笔记由 Fieldnotes 保存，由 Trip Fieldnotes 显示。

### 带入旅行

一篇笔记可以带进任意多次旅行，每次都可以选择以实时引用还是快照的方式加入。

| | 实时引用 | 快照 |
|---|---|---|
| 旅行中显示的内容 | 笔记的当前版本 | 加入旅行时的版本 |
| 你之后的修改 | 同步到旅行中 | 不会影响快照 |
| 图片 | 显示原笔记中的图片 | 保存一份副本 |
| 删除原笔记后 | 不再显示 | 仍然保留 |
| 你退出这次旅行后 | 私有笔记不再显示 | 仍然保留 |
| 适合 | 会持续更新的攻略、清单 | 需要原样保留的资料，例如出发前确认过的信息 |

### AI 助手

如果你使用连接了 TREK 的 AI 助手，它可以通过 `list_trip_notes` 这个工具，读取你有权访问的某次旅行中共享的笔记，例如回答「这次从昆明去大理的动车怎么订？」这样的问题。它以你的权限读取，看不到你无权访问的旅行，也不能修改任何内容。

## 权限

Fieldnotes 把你的笔记、文件夹和图片保存在自己那里，只向 TREK 申请上面这些功能需要的权限。它始终以你的身份行事，所以看不到你没有参加的旅行，也改不了你无权编辑的旅行。

| 权限 | 用途 |
|---|---|
| `db:own` | 保存你的笔记、文件夹、分享设置、旅行关联、快照和粘贴的图片。 |
| `db:read:trips` | 把笔记加入旅行时列出你的旅行和日程，推荐可以分享的人（与你同在某次旅行中的成员），以及读取旅行的地点、预订和住宿，用于快照里以卡片显示的行程内容。 |
| `db:read:files` | 找到来自旅行附件的图片。 |
| `db:read:files:content` | 显示这些图片，并在快照中保留一份副本。 |
| `db:meta` | 在你添加、移除或整理旅行笔记之前，确认你有权编辑这次旅行。 |
| `db:read:users` | 显示还有谁正在和你一起编辑笔记。 |
| `hook:user-data` | 导出 TREK 数据时把你的笔记一并导出，删除账户时一并删除。 |
| `mcp:tools` | 让连接了 TREK 的 AI 助手读取你有权访问的旅行中共享的笔记。TREK 管理后台会将其显示为「发布 AI 工具」。 |
| `http:outbound` | 显示笔记中链接自其他网站的图片。管理员允许该网站之前，这项功能保持关闭，私有网络地址也始终会被拦截。 |

## 安装与设置

1. 以管理员身份在 TREK 中打开 **管理后台 → 插件**。在「发现」中找到 **Fieldnotes** 和 **Trip Fieldnotes** 并安装；也可以从两个仓库的 Releases 页面下载 ZIP 文件，用「上传插件」手动安装。
2. 先启用 **Fieldnotes**，再启用 **Trip Fieldnotes**。新安装的插件默认处于停用状态。
3. 从导航栏打开 **Fieldnotes**，写下第一篇笔记。想分享给某次旅行时，打开笔记的 **共享** 窗口，使用 **带入旅行**。

> [!WARNING]
> 卸载 Fieldnotes 会删除它保存的所有笔记、文件夹和图片，卸载前请先备份 TREK。升级到新版本则会保留全部内容。

可选：在 Fieldnotes 的 **管理后台 → 插件 → ⋯ → 允许的主机** 中允许某些网站（例如 `*.example.com`）之后，笔记就能显示链接自这些网站的图片。直接复制图片再粘贴进笔记，则无需任何设置。

## 常见问题

- **谁能读到我的笔记？** 在你邀请别人、设为公开或加入旅行之前，只有你自己。实时引用对那次旅行的所有成员可见。
- **需要安装 Trip Fieldnotes 吗？** 想要完整的体验，需要。没有它，Fieldnotes 仍能把笔记带入旅行，但没有人能在旅行里读到；**在 Trip Fieldnotes 中打开** 也只会显示旅行的计划页。
- **我退出旅行后会怎样？** 那次旅行以实时引用方式关联的你的私人笔记将不再显示。快照会保留，因为旅行收到的是一份副本。
- **笔记存在哪里？能带走吗？** 存在你的 TREK 服务器上 Fieldnotes 自己的数据库里，不经过任何第三方服务。从 TREK 导出账户数据时，笔记会一并导出。想把某篇笔记带到别处，右键选择「复制为 Markdown」，属性和链接都会一并带上。
- **它不做什么？** 没有离线 App，也不和 Obsidian 或 Notion 双向同步：导入是一次性把笔记带进来，「复制为 Markdown」是把一篇笔记带出去。

## 开发者

仓库顶层就是可以直接安装的插件。源代码和测试位于 [`source/`](./source) 目录，Trip Fieldnotes 也由这里构建，修改都在这里进行。

```bash
cd source
npm ci
npm test         # 服务端、前端和翻译测试
npm run export   # 重新构建，并更新本仓库和同级 fieldnotes-trip 仓库中的插件文件
```
